# 탐뷰티 팝업 모델 이미지 폴더

3D 뷰어 v9+에서 사용할 모델 이미지를 이 폴더에 저장하세요.

## 권장 파일명

- `model-pink.jpg` — 핑크 체크 셔츠 + 클라우드블러 튜브 + 페치 그라데이션 배경
- `model-lilac.jpg` — 보라 배경 + 흩어진 제품 + 드림 무드
- `product-cloud-blur.jpg` — 클라우드블러 단독 제품컷
- `product-cloud-compact.jpg` — 클라우드 블러 컴팩트 (라일락 원형) 단독 제품컷

## 사용법

1. 위 파일명으로 이미지를 이 폴더에 저장
2. 3D 뷰어 v9 HTML 파일에서 자동으로 로드됨
3. 백패널 · 사이드 모델 패널 · 미션 사인에 표시됨

## 사이즈 권장

- 모델 사진: 1080×1440 (3:4) 이상
- 제품컷: 800×800 (1:1) 이상
- 포맷: JPG (용량 1MB 이하 권장)
