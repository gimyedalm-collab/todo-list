01 · REUSE STRATEGY

재사용 설계 원칙 5가지

"다음 팝업에서도 70% 그대로" 목표로 v1에서 조정한 핵심 원칙

1. 모듈러 큐브 단상 (가장 큰 자산)

  • 큐브 단상 3종 (S/M/L)을 표준 사이즈로 발주 → 다음 팝업에서 조합·재배치만 변경
  • 화이트 + 분리 가능한 컬러 시트 래핑 → 시트만 갈아끼우면 컬러 톤 변경 가능
  • v1처럼 컨셉 전용 일체형 단상 ✗ — 다음 팝업 컨셉 바뀌면 폐기

2. 컬러월·미러는 프레임 표준화

  • 립 컬러월은 프레임만 모듈형, 스워치 패널은 교체식 → 다음 팝업 새 컬러 라인업이면 패널만 교체
  • 풀바디 미러는 렌탈 ✗ → 자가 보유 (자주 쓰는 자산)
  • 고정 컬러 그래픽이 일체화된 컬러월 ✗

3. 솜털 오브제 = 브랜드 시그니처 자산

  • 탐뷰티 = "보송·솜털" 무드는 향후 1-2년 핵심 아이덴티티 → 대형 솜털 오브제 자가 보유
  • 분해·보관 가능한 구조로 제작 (Ø80cm를 2분할 또는 4분할 분해)
  • 다음 팝업에서도 시그니처로 활용 가능

4. 일회성은 인쇄·소모품으로만

  • 존별 벽면 그래픽·헤더 사인 = 이번 컨셉 전용 → 일회성으로 분류 (재사용 ✗)
  • 해시태그 사이니지·QR 카드·카탈로그 = 인쇄물, 매번 새로 제작
  • 샘플 파우치·쇼핑백 = 소모품, 매번 새로

5. 보관·물류 비용 포함 계산

  • 재사용 자산은 창고 보관비 (월 5-15만원) 발생 → 분담 비용에 반영
  • 롯데 명동 → 창고 → 다음 팝업장 운반비 항목 별도 정리
  • 분해·재조립 매뉴얼 작업자 인계 필수
