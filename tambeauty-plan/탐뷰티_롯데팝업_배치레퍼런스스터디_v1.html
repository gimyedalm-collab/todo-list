04 · OUR LAYOUT VERDICT

v8 배치 검증 결과

10개 케이스 + 5패턴에 비추어 — 우리 v8은 어디 강하고 어디 약한가

v8 = Center-Hero + Linear Flow + Vertical Stack 3중 하이브리드

우리는 단일 패턴이 아니라 세 패턴을 동시에 차용한 하이브리드. ③ 중앙 BEST 원형 단상(Center-Hero) + ①→②→③→④→⑤ 좌→우 흐름(Linear Flow) + 헤더·디스플레이·진열·바닥 세로 적층(Vertical Stack).
→ 결론: K-뷰티 작은 부스 팝업 베스트 프랙티스에 부합. 단, 5섹션이 약간 빡빡하다는 점이 약점.

✓ KEEP

v8에서 잘 한 것 (유지)

  • 중앙 ③ BEST 원형 단상 = Center-Hero ★
  • 좌→우 카테고리 흐름 = Linear Flow ★
  • 헤더+컬렉션 띠+디스플레이 = Vertical Stack ★
  • 미러 백패널 (3CE식) — 럭셔리 무드
  • LED 스트립 (헤라식) — 시그니처 빛
  • 패브릭 러너 (에뛰드식) — 텍스처
  • 식물·꽃 (어뮤즈식 절제 1개씩)
  • 한·중·일 카피 풀라인 — 타깃 직격
! REVISIT

v8에서 재검토할 것

  • 5섹션 = 너무 많음. 시선 분산 가능 (4섹션으로?)
  • 좌측 ①+② 두 단상 너무 좁게 붙음
  • 우측 ④+⑤ 마찬가지 빡빡
  • 굿즈 3종(Cloud Passport·Edition Box·Mirror Card)이 카운터 위 흩어져 있어 한 군데 보고 싶을 수 있음
  • 미션 사인 비스듬 배치 → 정면에서 시선 빼앗김 가능
  • 해시태그 네온 4개 = 시각 정보 과다 (2개로?)
  • 막대 오브제 없는데 컬렉션 띠·골드 트림으로 보완 — OK인지 확인
